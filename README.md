# Night Camp Build Planner

A one-screen build planner for **Night Camp**: class, skills, stats, runes and gear, with live data from the official wiki.

Made by **[Zynnlol Gaming](https://www.facebook.com/zynnlolgaming)** · แพลนเนอร์บิลด์ Night Camp รองรับภาษาไทย (กดปุ่ม EN/TH)

**Open the planner:** https://zynnlolgaming.github.io/nightcamp-planner/

## Features
- Everything on one screen: equipment, stats and every skill tree in your job path
- Game-accurate stat points (rising cost), stat cap, shared skill points and free skill levels
- Live wiki data: correct icons, new items, official Thai names
- **Import your real character** with a build code: exact stats, skills, runes, gear with your real rolls, item grades and options
- **🏆 Best Gear**: ranks every usable item per slot for your build, with where it drops
- 3 build slots, share links, notes
- **English / ไทย** switch (official Thai names from the wiki)

## Get a build code from the game
Click **🧩 Install Build Export** in the planner for step-by-step help (English + Thai). Two options:
1. **Bookmark** (easiest, no install): drag it from the planner's Import window to your bookmarks bar, then click it in the game
2. **Chrome extension**: download [nightcamp-build-export.zip](nightcamp-build-export.zip), unzip, load it in `chrome://extensions` (Developer mode → Load unpacked)

The exporter is read-only: it copies your build only, never your name, account, coins or inventory, and never sends anything anywhere.
